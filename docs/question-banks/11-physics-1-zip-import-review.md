## Beginner review and approval workflow

1. Open one linked bank JSON file. Each question contains prompt, options, a zero-based correct index (0=A, 1=B, 2=C, 3=D), explanation, source and verification.
2. Have a qualified physics reviewer solve each item independently, check all four options, units, dimensions, solution depth, assumptions, chapter fit and difficulty. Resolve its listed flags. For repeated tasks, revise one or retain only one for approval; keep the others as drafts. Do not use this import's author checks as independent academic approval.
3. Record the decision by question ID, reviewer, date, changes and the owner's publication approval. Rebalance answer positions carefully and recompute the correct index whenever options move. Run the tests after any edits; their derivations may also need a reviewed update if question content changes.
4. Keep verification.status as draft until those checks and owner approval are complete. Only then edit the selected existing question in place to verification.status = verified and put the real reviewer/date/approval record in verification.method. Do not create an approved duplicate file or rerun --write with the same IDs: global ID validation correctly rejects that.
5. Run pnpm test, pnpm typecheck and pnpm report:mock. The generated report shows the new approved counts. Changing a status to verified enables eligible tests immediately on a local server reading these files; it is not just a review label. No blanket approval or status-switching command is provided.
6. Open http://127.0.0.1:3000/lectures/physics/1/detailed#chapter-mock-test after selecting Class 11 and Physics. Refresh availability. Easy 10 enables at 10 approved Easy questions; Medium 10/20 at their thresholds; Hard 10/20/30 at theirs. Questions must satisfy their final reviewed difficulty. Until then, Start remains disabled.

The current importer has no separate academic approval UI or reviewer identity enforcement; verification metadata is a source-file editorial workflow. Nothing in this task grants or records a fictional human approval.
